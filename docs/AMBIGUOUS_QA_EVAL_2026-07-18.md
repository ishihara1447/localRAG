# 曖昧質問 耐性評価（防衛白書 15問ペア） 2026-07-18

実ユーザーは年度・正式名称・限定条件を省いて曖昧に質問する。その聞き方でも
OTE-RAG が正答できるかを測るため、`scripts/hakusho-eval.py` の30問から15問を選び、
**採点基準（正解キーワード/正規表現）は同一のまま質問文だけを曖昧化**して、
明確版と曖昧版を同一実行内で対比した。

## 失敗モード分析

### Q4（唯一の失敗）: 拒否（refusal）— 原因は検索段階の語彙依存

- 質問: 「三文書っていつ決まった？」→ 応答: 「提供された文書には該当する情報がありません。」
- 誤答・ハルシネーションではなく誠実な拒否。
- **追試（同一実行後に単発プローブで確認）**:
  - 「三文書っていつ**閣議決定**された？」→ **正答**（令和4年12月16日）
  - 「**防衛の**三文書っていつ決まった？」→ 依然拒否（分野ヒントでは回復しない）
- **検索チャンクの検証**: 失敗版では取得8チャンク全てが「三文書」を含むが
  「12月16日」を含むチャンクは0件。正答版では「閣議決定」の語で日付入りチャンクが
  2位に取得されていた。つまり**生成ではなく検索の失敗**。「決まった」という口語動詞
  では、日付が書かれたチャンク（「閣議決定」表記）に辞書的にも意味的にも届かなかった。

### 準失敗モードとしての「候補列挙型応答」（3問: Q09・Q12・Q30）

キーワード採点上は OK だが、単一の直接回答ではなく複数候補の列挙で正解を含めた形:

- Q09「防衛費っていくら？」→ 43兆円程度（5年間計画）/ 9.9兆円（2025年度合計）/
  **8兆4,748億円（2025年度歳出）** の3候補を列挙
- Q12「防衛費ってGDPの何％？」→ 世界2.5% / **日本1.4%** / ロシア6.3% / 目標2% など
  7項目を国・時期別に整理して列挙
- Q30「部隊をまとめて指揮するトップって何て役職？」→ **統合作戦司令官**と統幕長の
  2役職を役割の違い付きで列挙

列挙の内容は白書の記述に忠実で、取り違えではない。ただし実ユーザー視点では
「どれが自分の聞きたい数字か」を自分で選ぶ必要があり、単一回答と同じUXではない。
過少指定質問に対する現行モデルの挙動は「拒否でも決め打ちでもなく、条件別に列挙する」
というグレースフルな縮退であることが確認できた。

## clarification（問い返し）機能の効果見込み

タイプ別に、曖昧質問を具体化する問い返し機能が効きそうかの考察:

| type | 効果見込み | 根拠 |
|------|-----------|------|
| underspecified | **高**（ただし代替あり） | Q09/Q12/Q30 は複数候補があることをモデル自身が検出できており、「2025年度の歳出額ですか、5年間の総額ですか？」という問い返しの材料は既に応答内に揃っている。現状の候補列挙でも実用にはなるため、問い返しは「列挙が長くなりすぎる場合のUX改善」として効く |
| colloquial（語彙欠落型） | **高** | Q4 の追試が直接の根拠。「決まった＝閣議決定のことですか？」の一往復、あるいは問い返しなしでも「クエリを公式語彙で言い換えて再検索する」自動リフォーミュレーションで回復できることが実証された。拒否応答を返す前に言い換え再検索を1回挟む設計が最も費用対効果が高い |
| pronoun | 低（今回の範囲では不要） | 2/2 正答。ハイブリッド検索＋埋め込みが指示語・通称を吸収した |
| typo | 低（今回の範囲では不要） | 2/2 正答。1文字誤字は意味検索が吸収した |
| omission | 低〜中 | 3/3 正答だが、うち1問（Q09）は候補列挙で回収した形。年度省略は underspecified と地続きであり、文書内に複数年度の数値が併存する題材では問い返しの価値が出る可能性がある |

要するに、優先すべきは（1）拒否前の**クエリ自動言い換え再検索**（Q4型の回復、
ユーザーへの問い返し不要）、（2）候補が複数あるときの**問い返しまたは列挙の要約提示**
（Q09/Q12型のUX改善）の2点。全質問に一律で問い返すゲートは、14/15が問い返し無しで
正答している以上、過剰と判断する。

## 制約・注意

- n=15・単一実行。temp=0 で決定的だが、設問サンプリングの偏りは残る（hakusho-eval の
  d カテゴリ「白書外の質問」は曖昧化の意味が薄いため除外した）
- 曖昧版の質問文は評価者（Claude）が作文したもので、実ユーザーの発話ログではない。
  実ユーザーはさらに極端な断片（単語のみ等）で聞く可能性がある
- 単一文書（防衛白書）・単一ドメインでの結果。複数文書ワークスペースでは
  underspecified の衝突候補が増え、成績が下がる可能性が高い
- キーワード採点は「正解を含む列挙」を OK と数える。単一直接回答率で採点し直すと
  曖昧版は 11/15 相当（列挙型3問を部分回答扱いにした場合）になる点に留意
