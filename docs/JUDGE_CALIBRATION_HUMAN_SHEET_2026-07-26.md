# judge キャリブレーション用 人手ラベルシート

## この作業は何のためか

**AIの自動採点（judge）が信用できるかを測ります。** judgeが「正しい」と言ったものが本当に正しいか、人間の目で確認する作業です。
これをやらないと、**AIが自分で採点して自分に甘い点をつけている**状態が続きます。実際、これまでに採点の欠陥が5例見つかり、**うち4例は「甘い方向」の誤り**でした。

## やること

**26件について `YES` / `NO` / `?` のどれかを書くだけです。**

- 所要時間の目安: **20〜30分**
- 読む回答は **15本**（1本の回答に複数の判定がぶら下がります）
- **途中でやめて大丈夫です。** 書いたところまでで計算できます
- **このファイルに直接書いてください**（`- label:` の行に追記）
- **書き終わったら「シート記入したよ」と言ってください。** 集計はこちらでやります（コマンド実行は不要です）

## 判定の基準

各項目の「**判定したい内容**」を、回答が**述べているかどうか**だけを見てください。

| 書くもの | どういうとき |
|---|---|
| **`YES`** | 回答がその内容を**述べている**（表現が違ってもよい。内容が合っていればYES） |
| **`NO`** | **述べていない**、または**間違ったことを述べている** |
| **`?`** | **判断がつかない**（集計から除外します。遠慮なく使ってください） |

### 迷いやすいケースの扱い（事前に決めてあります）

| ケース | どうするか |
|---|---|
| 内容は合っているが**言い回しが違う** | **`YES`**（表現の一致は求めていません） |
| 内容は合っているが**数値の桁や単位が違う** | **`NO`**（数値の正確さは重要です） |
| **一部だけ**述べている（3つ挙げるべきところ2つだけ等） | **`NO`**（その要素を満たしていないため） |
| 述べてはいるが**回答全体としては的外れ** | **`YES`**（「良い回答か」ではなく「その1点を述べているか」だけを見ます） |
| 回答が**曖昧でどちらとも取れる** | **`?`** |

> **judgeがどう判定したかは、このファイルの末尾にまとめてあります。**
> **先に見ないでください。** 見てから記入すると判断が引きずられ、測定の意味がなくなります。
