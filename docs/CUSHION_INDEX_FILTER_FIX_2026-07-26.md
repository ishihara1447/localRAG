## 2. 判定条件をどう変えたか

### 変更内容（実質2行の追加）

```js
function looksLikeIndexEntry(sentence = "") {
  const digits = (sentence.match(/[0-9０-９]/g) || []).length;
  const slashes = (sentence.match(/[／/]/g) || []).length;
  // 数字が多く句点が無い（＝文でない）ことが前提条件
  if (!(slashes >= 1 && digits >= 8 && !/[。！？]/.test(sentence))) return false;
  // そのうえで「用語 ／ ページ番号, ページ番号, ...」の並びが2回以上あるものだけを索引行とみなす
  const pageRefRuns = (sentence.match(/[／/]\s*\d+(?:\s*,\s*\d+)+/g) || []).length;
  return pageRefRuns >= 2;
}
```

**設計上の要点: 旧条件を前段にそのまま残し、条件を追加（＝狭める）だけにした。**
これにより**「本修正で新たに捨てられる文」は原理的に発生しない**（新述語が真になるのは旧述語が真だった場合のみ）。退行方向のリスクを構造的にゼロにする、という意図である。

#### 何が起きたか（実物で確認）


#### 評価

- **数値の捏造はない。金額の取り違えもない。** 18,500円は**即応予備自衛官の見出しの下に置かれており、帰属は正しい**。4つの数値要素すべてが原典と一致する（だから同時に `Q11 2/4 → 4/4` に改善している）
- **誤りは名称の略記**である。原典の `即応予備自衛官手当` を `予備自衛官手当` と書いており、正規表現は見出しの文脈を見られないためこれを「取り違え」と判定した
- ただし**完全な誤検出とも言い切れない**。その行だけを抜き出して読むと「予備自衛官の手当が18,500円」と読めてしまうため、**表記として実際に紛らわしい**
- **重要な補足**: BEFORE が 0/20 だったのは、**Q11 で 18,500円 にも 17,100円 にも一切言及していなかったから**でもある（BEFORE は 2/4 で、両方を落としていた）。**答えなければ [X] は踏まない。** ハルシネーション0の一部は「情報が届いていなかったこと」に支えられていた

#### 対応方針
