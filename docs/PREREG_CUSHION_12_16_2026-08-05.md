## 4. 測り方

- 166問（1,044要素）を生成 → **修理した判定器**で採点
- 出荷構成: LLM `granite4.1:8b` / 埋め込み `granite-embedding:278m` /
  リランカー `japanese-reranker-xsmall-v2` / topN=8
- ワークスペース `emb-granite`（再埋め込み不要）
- 条件ごとにコンテナを作り直し、**`printenv` で値を実測検証**する
- `[X]` は LLM 二次判定つき（`--judge-model gemma4:12b`）

**1run とする。** 3run にしないのは、前回 3条件×3run が
すべて完全一致（ばらつき0）で、条件内分散がほぼ無いと実測済みのため。
🔴 したがって**差が1〜2要素の場合は「差があった」と言わない。**
