## 9. 逸脱の記録（実装後・2026-08-05）

### 9-1. 🔴 §3 で決めた方式が目的を果たさず、方式を変更した

機械的ガード（G1 否定語尾 / G2 文境界）を実装して測った結果:

| 基準 | 予想 | **実測** |
|---|---|---|
| P1 誤検出10件の救済 | 8/10 | **3/10** |
| P2 真の捏造3件の検出 | 3/3 | **3/3** ✅ |

**P2 は合格したが P1 が 3/10 で、捏造を測れるようにするという目的を果たさない。**

### 9-2. なぜ外れたか — 誤検出の型が分類より多様だった

残る7件を診断した結果、**否定語尾でも文境界でもない型**が主だった。

| 設問 | 一致箇所 | 真の理由 |
|---|---|---|
| Q075 | 「在日米軍施設**よりも**約836km²**大きい**」 | **比較の向きが逆**（正しく書いている） |
| Q079 | 「任期満了退職者**よりも大幅に多く**、2,456」 | 同上 |
| Q088 | 「機能別で4つ、地域別で7つ」 | 正しい数値。離れた語同士が一致 |
| Q090 | 「戦車や火砲の数の減少・増加」 | 否定が**30字より先**（「提供されていない」） |
| Q091 | 「沖縄分を**合わせて**見ると」 | 「合わせて」＝比較していない |
| Q092 | 「NATOはそれぞれ「気候強靱性」 | 文の切れ目をまたいで語をつないだ |
| Q038 | 「NPTは191の国・地域」 | 正しい数値 |

**「AよりもBが大きい」を「Bが大きい」と読む型が2件**あり、これは
**比較の向きを理解しないと判別できない**。正規表現では原理的に無理である。

### 9-3. 変更後の方式

§3 で「LLM-as-judge は揺れが入るから採らない」と書いたが、**これを撤回する。**

| 段 | 役割 |
|---|---|
| **決定的判定（既存＋G1/G2）** | **一次フィルタ**。発火しなければ捏造なしとして確定（高速） |
| **LLM 判定** | **発火した件だけ**に適用し、真偽を判定 |
| 揺れ対策 | 同一入力で3回判定し**多数決**。3回が割れたら**人手確認に回す**（自動では決めない） |

発火は166問中11件なので、LLM 判定の対象は小さく、揺れも多数決で抑えられる。

**G1/G2 は残す。** 3件を機械的に落とせる分、LLM 判定の対象が減る。

### 9-4. 合否基準の扱い

**P1〜P5 は変更しない。** 方式を変えただけで、達成すべき水準は動かさない。
P1（誤検出10件の救済）が達成できなければ、この修理は失敗として記録する。
