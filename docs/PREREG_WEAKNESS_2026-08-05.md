## 4. 「弱点」の定義（★測定前に確定）

以下をすべて満たすものを弱点と呼ぶ。

| # | 条件 |
|---|---|
| W1 | 決定的判定で**不正解**（要素が取れていない） |
| W2 | **同一カテゴリ内で3問以上**に共通する（単発の失敗は弱点と呼ばない） |
| W3 | 原因が **検索側・生成側のどちらかに切り分けられている** |

### 攻める対象の選び方

**W1〜W3 を満たすもののうち、影響する要素数が多い上位3つ**に絞る。

**4つ以上には手を出さない。** 原則1「一度に複雑なことをやらない」に従い、
1つずつ事前登録つきで検証する。

### 弱点と呼ばないもの

- **C6（unanswerable）の検索カバー率が低いこと。** 答えが無い設問なので設計どおり
- 1問だけの失敗（W2 で除外）
- 原因が切り分けられないもの（W3 で除外）。「たぶん検索が悪い」では着手しない
