# OTE-RAG v1.2.9 (Windows x64)

**完全ローカルで動く日本語RAG。**取り込んだ文書は一切外部へ送信しません。
LLM・埋め込み・リランカーをすべて同梱しており、**動作中に外部へ取りに行かない設計**です。
（ただし完全にネットワークを遮断した状態での通し動作は未検証です。下記「未検証の事項」参照）

---

## 🔴 アップグレードする方へ — 文書の再取り込みが必要です

**v1.2.8 以前からアップグレードする場合、取り込み済みの文書をすべて入れ直してください。**

文書検索に使うモデルを差し替えたため、**これまでのベクトルデータと互換性がありません**
（1024次元 → 768次元）。再取り込みをしないと、検索が正しく動きません。

**新規に導入される場合は、この作業は不要です。**

## v1.2.8 からの変更

### 文書検索モデルを中国系でないものへ差し替えました

**これで、同梱するすべてのAIモデルが中国系でなくなりました。**

| 種別 | v1.2.8 | v1.2.9 |
|---|---|---|
| 生成AI | granite4.1:8b（IBM・米） | 同左 |
| **文書検索** | **bge-m3（BAAI・中国）** | **granite-embedding:278m（IBM・米）** |
| 並べ替え | japanese-reranker-xsmall-v2（日本） | 同左 |

新しい文書検索モデルは **Apache-2.0** で、サイズも 1,158MB → **562MB** と半分以下です。

### 精度は同等以上です

防衛白書（544ページ）で、同一条件・同じ日に測り直して比較しました。

| | v1.2.8（bge-m3） | **v1.2.9（granite-embedding）** |
|---|---:|---:|
| **検索の正解率**（165問・上位8件） | 0.7120 | **0.7284（+1.64pt）** |
| 回答の正解数（30問） | 28/30 | **27/30（−1問）** |
| 応答時間 中央値 | 4.9 秒 | **5.0 秒** |

**検索は上回り、回答は1問減りました。**

> **v1.2.8 の Release ページには「27/30」と記載しています。** 上表の 28/30 は
> 今回 v1.2.9 と同じ日・同じ手順で測り直した値で、測定時期が異なります。
> どちらも正しい測定ですが、**比較には上表の数値（同一条件）をお使いください。**

<details>
<summary>回答の内訳（クリックで展開）</summary>

| 設問の種類 | v1.2.8 | v1.2.9 |
|---|---:|---:|
| 直接的な事実を問う /8 | 8 | 8 |
| 数値を判別する /6 | 6 | 6 |
| 定義を説明する /6 | 5 | 5 |

減ったのは「言い換えて問う」設問1問です。**「文書に書かれていないことを問う」設問は
5/5 を維持**しており、知らないことを答えてしまう挙動は増えていません。

各3回ずつ測定し、**3回とも1問単位で完全に同じ結果**でした（測定の再現性は確認済み）。

</details>

## 🔴 未検証の事項

**VRAM 8GB のPCでの動作は、誰も確認していません。**

- 見込みは 16GB のPCで測った値からの引き算です。**余裕はほとんどありません**
- 今回の差し替えで文書検索モデルが 600MB 小さくなったため、**v1.2.8 より有利**にはなりました
- ブラウザなど GPU を使うアプリが動いていると、CPU 動作へ転落し**回答が非常に遅くなる**ことがあります

**そのほか未検証のもの**

- **この版でのインストールの通し実行。** ビルドと結合の検証は行いましたが、
  **v1.2.9 パッケージから実際にインストールを完走させた記録はありません**
- **配布物そのものでの精度・速度。** 上記の数値は開発環境（Docker版）での測定です
- **8GB のPCでの速度**
- 完全にネットワークを遮断した状態での通し動作
- 再起動をまたいだ動作
- **文書検索モデルの入力上限が 512 に短くなりました**（従来は 8192）。
  防衛白書544ページの取り込みでは問題ありませんでしたが、極端に長い文書での影響は未確認です

## 必要なもの

| 項目 | 条件 |
|---|---|
| OS | Windows 10 / 11 (x64) |
| GPU | NVIDIA製・**VRAM 8GB 以上**（16GB 推奨。8GB は上記のとおり未検証） |
| **CPU** | **AVX2 対応**（下記参照） |
| ディスク空き | **40GB 以上**（作業用。**製品本体は約9.9GB**） |
| 権限 | インストールに**管理者権限**が必要 |
| ネットワーク | **不要**（ダウンロード時のみ必要） |

> **ディスク容量について**
> インストール中は「結合したZIP（約8GB）」「一時展開（約9.9GB）」「インストール先（約9.9GB）」が
> **同時に存在**します。インストーラーは実行時点で 20GB の空きを要求するため、
> **開始時に 40GB 以上**空けてください。
>
> 🔴 **結合が終わったら、Setup.exe を実行する前に分割ファイル（`.001`〜`.005`）を削除してください。**
> 残したままだと **48GB 以上**必要になり、足りないとインストーラーが
> 「20GB 以上の空き容量が必要です」で停止します（約8GB の照合と約10GB の展開を
> 終えた後に停止するため、10分以上待たされます）。
>
> **インストール先を C: 以外にする場合でも、C: に約 22GB の空きが必要です。**
> 一時展開先（`C:\OTR\<日時>`）とモデルの置き場（`C:\ProgramData\LocalRAG`）が
> C: 固定のためです。

> **🔴 AVX2 について**
> 並べ替えモデルは AVX2 という CPU 命令に最適化されています。
> **対応していない CPU では、エラーにならず静かに遅くなる・精度が落ちる可能性があります**
> （実際にどうなるかは確認できていません）。
> 2013年以降の Intel Core i シリーズ・2015年以降の AMD であれば通常対応しています。

## インストール手順

### 1. ダウンロード

このReleaseから**すべてのファイル**を**同じフォルダ**に保存してください。

| ファイル | 用途 |
|---|---|
| `OTE-RAG-Setup.exe` | インストーラー本体 |
| `OTE-RAG-win64-v1.2.9.zip.001` 〜 `.005` | 製品データ（5分割） |
| `OTE-RAG-win64-v1.2.9.zip.sha256` | 照合値（**インストーラーが必須とします**） |
| `Join-OTE-RAG.cmd` | **結合スクリプト** |
| `MANIFEST.txt` | 照合値 |
| `README.txt` | このフォルダでの手順 |

### 2. 結合

**`Join-OTE-RAG.cmd` をダブルクリックしてください。**
分割ファイルを1つに戻し、**破損していないか SHA-256 で自動検証**します。

<details>
<summary>手動で結合する場合（クリックで展開）</summary>

```cmd
copy /b OTE-RAG-win64-v1.2.9.zip.001+OTE-RAG-win64-v1.2.9.zip.002+OTE-RAG-win64-v1.2.9.zip.003+OTE-RAG-win64-v1.2.9.zip.004+OTE-RAG-win64-v1.2.9.zip.005 OTE-RAG-win64-v1.2.9.zip
certutil -hashfile OTE-RAG-win64-v1.2.9.zip SHA256
```

表示された値が `MANIFEST.txt` の「元SHA-256」と一致すれば正常です。

</details>

### 3. 🔴 分割ファイルを削除する

結合できたら、**`.001`〜`.005` を削除してください。**
残したままインストールすると、容量不足で失敗します。

### 4. インストール

**`OTE-RAG-Setup.exe` をダブルクリックするだけです。**

- 管理者権限を求められたら「はい」を選んでください
- **古いバージョンが入っている場合は、自動で検出してアンインストールします**
  （文書データは `C:\ProgramData\LocalRAG\uninstalled-<日付>` へ退避されます）
- インストール先とポート番号は画面で変更できます（既定: `C:\LocalRAG` / ポート 3001）
- 完了するとブラウザが自動で開きます

> Windows が「発行元不明」の警告を出すことがあります。
> **Setup.exe には署名を付けていません。** 「詳細情報」→「実行」で進めてください。

### 5. 最初の設定

ブラウザで管理者アカウントの作成画面が出ます。**必ずパスワードを設定してください。**

**アップグレードの場合は、ここで文書を入れ直してください。**
