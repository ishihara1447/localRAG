# OTE-RAG v1.2.7 (Windows x64)

**完全ローカルで動く日本語RAG。**取り込んだ文書は一切外部へ送信しません。
LLM・埋め込み・リランカーをすべて同梱しているため、**インターネットに接続していないPCでも動作します。**

---

## 必要なもの

| 項目 | 条件 |
|---|---|
| OS | Windows 10 / 11 (x64) |
| GPU | NVIDIA製・VRAM 12GB以上を推奨（RTX 5070 Ti相当） |
| ディスク空き | **ピーク時 約32GB**（インストール後は約21GB） |
| 権限 | インストールに**管理者権限**が必要 |
| ネットワーク | **不要**（ダウンロード時のみ必要） |

---

## インストール手順

### 1. ダウンロード

このReleaseから**すべてのファイル**を**同じフォルダ**に保存してください。

- `OTE-RAG-win64-v1.2.7.zip.001` 〜 `.006`（分割された本体）
- `MANIFEST.txt`（破損チェック用のハッシュ）
- `Join-OTE-RAG.cmd`（結合ツール）
- `OTE-RAG-Setup.exe`（インストーラ）

> **分割されている理由**: 本体は約10.5GBあり、GitHubのRelease添付は1ファイル2GBまでのためです。
> 途中でダウンロードが切れても、**壊れたパートだけ取り直せます。**

まとめて取得する場合:

```powershell
gh release download v1.2.7 --repo ishihara1447/localRAG --dir C:\OTE-RAG-install
```

### 2. 結合する

**`Join-OTE-RAG.cmd` をダブルクリックしてください。** 管理者権限は不要です。

全パートを結合し、**SHA-256で破損していないか自動で検証**します。10GB前後あるため数分かかります。

> 7-Zipがある場合は `.001` を右クリック →「7-Zip」→「展開」でも結合できます。
> ただし**その方法ではハッシュ検証が行われません。**10GBのダウンロードは途中で壊れることがあるため、
> **`Join-OTE-RAG.cmd` を推奨します**（7-Zipで展開した後に実行して、検証だけ行うことも可能です）。

### 3. インストールする

**`OTE-RAG-Setup.exe` を右クリック →「管理者として実行」。**

zipの検証・展開・セットアップ・ブラウザ起動まで自動で行います。

---

## ⚠️ インストール時に出る警告について

**「WindowsによってPCが保護されました」と表示されます。**

これは `OTE-RAG-Setup.exe` に**コード署名証明書を付けていない**ためで、異常ではありません。
**「詳細情報」→「実行」**で進めてください。

心配な場合は、`MANIFEST.txt` に記載のSHA-256と実ファイルを照合して同一性を確認できます。

```powershell
certutil -hashfile OTE-RAG-Setup.exe SHA256
```

## v1.2.7 の変更点

**完全オフライン動作の保証**が主眼です。従来版には、オフライン環境で失敗する経路が3つ残っていました。

| 修正 | 内容 |
|---|---|
| **OCR（重要）** | テキスト層の無いPDF（スキャン文書）を取り込むと、文字認識用の言語データを外部CDNから取得しようとしていました。**通常の操作で発生**します。日本語・英語の言語データを同梱し、外部取得を無効化しました |
| **リランカー / 埋め込み** | 同梱モデルの配置がずれた場合に、Hugging Face等へ自動で取りに行っていました。外部取得を無効化し、不足時は日本語のエラーで明示的に停止します |
| **音声認識** | 音声ファイルの取り込み時にモデル（約250MB）を外部取得していました。無効化しました |
| 日本語OCRの既定化 | 従来は英語のみが対象で、日本語のスキャン文書が誤認識されていました |
| リランカーの無言故障 | モデル読込に失敗しても例外が握り潰され、**エラーを出さないまま検索精度が落ちる**状態でした。起動時に警告を出すようにしました |

いずれも、通信をフックして**外部アクセスが0回であることを実測**した上での修正です。

### 既知の制限

- **Setup.exe は未署名**です（上記の警告が出ます）
- **同梱していない言語のOCRはできません**（日本語・英語のみ）。外部からの自動取得は意図的に無効化しています
- 実機のオフライン環境での通しテストは未実施です

## 中身（約10.5GB の内訳）

| 素材 | サイズ |
|---|---|
| LLM・埋め込みモデル（gemma4:12b + bge-m3） | 8,311MB |
| Ollamaランタイム（CUDA含む） | 1,889MB |
| リランカー（bge-reranker-v2-m3 ONNX int8） | 561MB |
| Node ランタイム | 99MB |
| OCR言語データ（日本語・英語） | 8MB |

**サイズの大半はモデルです。**インストール時にネットワークから取得すれば約2.2GBまで縮みますが、
「顧客文書を外部に出さない・オフラインで動く」という本製品の中核要件を満たせなくなるため、同梱しています。
