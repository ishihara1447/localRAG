# OTE-RAG v1.2.8 (Windows x64)

**完全ローカルで動く日本語RAG。**取り込んだ文書は一切外部へ送信しません。
LLM・埋め込み・リランカーをすべて同梱しているため、**インターネットに接続していないPCでも動作します。**

---

## v1.2.7 からの変更

### 1. VRAM 8GB のPCを対象に加えました

**同梱する生成AIを、より小さいモデルへ差し替えました。**

| | v1.2.7 まで | v1.2.8 |
|---|---|---|
| 生成AI | `gemma4:12b`（Google） | **`granite4.1:8b`（IBM, Apache-2.0）** |
| 実測VRAM | 8.4 GB | **6.7 GB** |
| 埋め込みと合計 | 9.0 GB ← **8GBに載らない** | **7.3 GB** |

**精度は変わりません。** 防衛白書30問で同一条件・各3回ずつ測定し、
**27/30 対 27/30 の同点**でした。改善ではなく、同じです。

<details>
<summary>内訳では入れ替わりがあります（クリックで展開）</summary>

| 設問の種類 | v1.2.7 | v1.2.8 |
|---|---:|---:|
| 直接的な事実を問う /8 | 6 | **7**（+1） |
| 数値を判別する /6 | 5 | **6**（+1） |
| 定義を説明する /6 | **6** | 4（−2） |
| 白書に書かれていないことを問う /5 | 5 | 5 |
| 言い換えて問う /5 | 5 | 5 |
| **合計** | **27** | **27** |

合計が並んだのは、+2 と −2 が相殺した結果です。
なお定義説明の失点2問は、内容は正しいものの**定型句を言い換えたため**に
採点条件（「持たず・作らず・持ち込ませず」等の語を含むこと）を外したものです。
白書の用語をそのまま返してほしい用途では、この傾向が不利に働く可能性があります。

</details>

### 2. 検索結果を並べ替えるモデルを、中国系でないものへ差し替えました

| | v1.2.7 まで | v1.2.8 |
|---|---|---|
| リランカー | `BAAI/bge-reranker-v2-m3`<br>（中国・北京智源人工智能研究院） | **`hotchpotch/japanese-reranker-xsmall-v2`**<br>（日本、MIT） |
| サイズ | 570MB | **37MB** |
| 並べ替えの所要 | 約 4,400ms | **約 500ms**（実測で約1/9） |

系譜は `cl-nagoya/ruri-v3-pt-30m`（名古屋大学）← `sbintuitions/modernbert-ja-30m`
（SB Intuitions）で、**中国系の混入はありません。**

> **文書の再取り込みは不要です。** 文書検索に使う `bge-m3` は変更していないため、
> 既に取り込んだ文書はそのまま使えます。
> **その `bge-m3` は BAAI（中国）製のままです。** 変更すると全文書の再取り込みが
> 必要になるため本版では据え置いており、未解決の課題として残っています。

### 3. 配布サイズが 11.0GB → 8.5GB に縮みました

## 🔴 必ずお読みください — 未検証の事項

**VRAM 8GB のPCでの動作は、誰も確認していません。**

- 「7.3GB なので 8GB に載る」という見込みは、**16GB のPCで測った値からの引き算**です
- 8GB カードの実際に使える容量は、デスクトップ表示に取られる分を引いて
  **7.5〜7.8GB 程度**と見込まれます。**余裕はほとんどありません**
- ブラウザなど GPU を使うアプリが動いていると、メモリが足りずに
  **CPU 動作へ転落し、回答が非常に遅くなる**ことがあります

**8GBのPCへ導入される場合は、他のアプリを閉じた状態でお試しください。**
うまく動かない場合は、状況をお知らせいただければ対応を検討します。

**そのほか未検証のもの**

- 回答が出始めるまでの時間（本構成では測定していません）
- 完全にネットワークを遮断した状態での通し動作
- 再起動をまたいだ動作

## 必要なもの

| 項目 | 条件 |
|---|---|
| OS | Windows 10 / 11 (x64) |
| GPU | NVIDIA製・**VRAM 8GB 以上**（16GB 推奨。8GB は上記のとおり未検証） |
| **CPU** | **AVX2 対応**（🔴 v1.2.8 で新たに必要になりました。下記参照） |
| ディスク空き | **ピーク時 約28GB**（インストール後は約18GB） |
| 権限 | インストールに**管理者権限**が必要 |
| ネットワーク | **不要**（ダウンロード時のみ必要） |

> **🔴 AVX2 について**
> 新しい並べ替えモデルは AVX2 という CPU 命令に最適化されています。
> 旧モデルにこの依存はありませんでした。**対応していない CPU では、
> エラーにならず静かに遅くなる・精度が落ちる可能性があります**
> （実際にどうなるかは確認できていません）。
> 2013年以降の Intel Core i シリーズ・2015年以降の AMD であれば通常対応しています。

## インストール手順

### 1. ダウンロード

このReleaseから**すべてのファイル**を**同じフォルダ**に保存してください。

| ファイル | 用途 |
|---|---|
| `OTE-RAG-Setup.exe` | インストーラー本体 |
| `OTE-RAG-win64-v1.2.8.zip.001` 〜 `.005` | 製品データ（5分割） |
| `Join-OTE-RAG.cmd` | **結合スクリプト**（下記で使います） |
| `MANIFEST.txt` | 照合値（結合スクリプトが参照します） |

### 2. 結合

**`Join-OTE-RAG.cmd` をダブルクリックしてください。**
分割ファイルを1つに戻し、**破損していないか SHA-256 で自動検証**します。

`OTE-RAG-win64-v1.2.8.zip`（約8.5GB）ができれば成功です。

<details>
<summary>手動で結合する場合（クリックで展開）</summary>

コマンドプロンプトで、保存したフォルダに移動して:

```cmd
copy /b OTE-RAG-win64-v1.2.8.zip.001+OTE-RAG-win64-v1.2.8.zip.002+OTE-RAG-win64-v1.2.8.zip.003+OTE-RAG-win64-v1.2.8.zip.004+OTE-RAG-win64-v1.2.8.zip.005 OTE-RAG-win64-v1.2.8.zip
certutil -hashfile OTE-RAG-win64-v1.2.8.zip SHA256
```

表示された値が `MANIFEST.txt` の「元SHA-256」と一致すれば正常です。

</details>

### 3. インストール

**`OTE-RAG-Setup.exe` をダブルクリックするだけです。**

- 管理者権限を求められたら「はい」を選んでください
- **古いバージョンが入っている場合は、自動で検出してアンインストールします**
  （文書データは `C:\ProgramData\LocalRAG\uninstalled-<日付>` へ退避されます）
- インストール先とポート番号は画面で変更できます（既定: `C:\LocalRAG` / ポート 3001）
- 完了するとブラウザが自動で開きます

> Windows が「発行元不明」の警告を出すことがあります。
> **Setup.exe には署名を付けていません。** 「詳細情報」→「実行」で進めてください。

### 4. 最初の設定

ブラウザで管理者アカウントの作成画面が出ます。**必ずパスワードを設定してください。**
