# OTE-RAG（Linux版）導入の手引き

**このページから始めてください。** 順番に進めれば導入できます。

OTE-RAG は、社内の文書を読み込ませて日本語で質問できるようにするツールです。
**文書も AI も、すべてサーバーの中だけで動きます。** 外部のクラウドサービスへ
文書が送られることはなく、インターネットに接続していない環境でも動作します。

---

## 導入までの流れ

```
  ① 環境を調べる  →  ② 資材を受け取る  →  ③ 結合する  →  ④ 導入する
     （5分）            （12GB）           （5分）        （15分）
```

---

## ① まず環境を調べる（所要 5分）

**必ず最初に実施してください。** 導入先のサーバーが要件を満たしているかを確認します。

このページの `survey-target.sh` をダウンロードし、**導入先のサーバー**で実行します。

```bash
bash survey-target.sh > survey.txt
```

読み取りだけを行うスクリプトです。設定の変更やファイルの作成は一切しません。
外部への通信も行いません。

**結果の見かた**

| 表示 | 意味 |
|---|---|
| `[OK]` | 問題ありません |
| `[注意]` | 確認したほうがよい項目です。多くはそのまま進められます |
| `[NG]` | **導入前に解決が必要です。** そのままでは動きません |

`[NG]` が出た場合は、`survey.txt` を保守担当へお送りください。

**主な要件**（詳しくは同梱の `INSTALL_GUIDE.md`）

- RHEL 9（x86_64）
- Docker Engine と `docker compose`（v2 以降）
- NVIDIA GPU（VRAM 16GB 以上）と `nvidia-container-toolkit`
- 空き容量 40GB 以上

> **GPU まわりは特にご注意ください。**
> `nvidia-container-toolkit` が入っていないと、GPU があっても使われず、
> 回答に数分かかる状態になります。オフライン環境では後から入れるのが
> 難しいため、導入前の確認をおすすめします。

---

## ② 資材を受け取る（12GB）

このページから次をダウンロードしてください。**すべて同じフォルダに置きます。**

| ファイル | 用途 |
|---|---|
| `ote-rag-linux-x64-v1.1.1.tar.gz.001` 〜 `.007` | 配布物本体（7分割） |
| `MANIFEST.txt` | 各ファイルの照合値 |
| `join.sh` | 結合用スクリプト |

12GB あるため、`gh` コマンドが使える環境では次が確実です。

```bash
gh release download linux-v1.1.1 --repo ishihara1447/localRAG
```

---

## ③ 結合する（所要 5分）

```bash
bash join.sh
```

分割ファイルを1つに戻し、内容が正しいかを自動で検証します。
`ote-rag-linux-x64-v1.1.1.tar.gz`（約12GB）ができれば成功です。

---

## ④ 導入する（所要 15分）

```bash
tar xzf ote-rag-linux-x64-v1.1.1.tar.gz
cd ote-rag-linux-x64-v1.1.1
sudo ./install.sh
```

**導入後**: ブラウザで `http://localhost:3001` を開き、
最初に管理者パスワードを設定してください。

主なオプション（`sudo ./install.sh --help` で全一覧）

| オプション | 用途 |
|---|---|
| `--data-dir <パス>` | 文書とモデルの置き場所を変える（既定は `/opt/ote-rag/data`。約11GB使います） |
| `--port <番号>` | Web の待ち受けポートを変える（既定 3001） |
| `--install-root <パス>` | プログラムの置き場所を変える（既定 `/opt/ote-rag`） |

詳しい手順・トラブル対応は、展開後の `INSTALL_GUIDE.md` にあります。
このページからも同じものをダウンロードできます。

---

## 導入後の操作

```bash
sudo /opt/ote-rag/start.sh       # 起動
sudo /opt/ote-rag/stop.sh        # 停止
sudo /opt/ote-rag/uninstall.sh   # 削除（文書とモデルは残ります）
```

**アンインストールしても、取り込んだ文書は削除されません。**
完全に消す場合は `--purge` を付けてください。

---

## 困ったときは

| 症状 | 確認すること |
|---|---|
| `install.sh` が途中で止まる | 表示されたエラーの内容。導入前の状態に自動で戻ります |
| 回答が返るが極端に遅い | GPU が使われていない可能性があります。`nvidia-smi` と toolkit の導入状況 |
| ブラウザで開けない | `cd /opt/ote-rag && docker compose ps` でコンテナの状態 |

解決しない場合は、次をお送りいただければ調査できます。

```bash
bash survey-target.sh > survey.txt
cd /opt/ote-rag && docker compose logs --tail=200 > logs.txt
```
